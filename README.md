## A few things I've worked on

### [Spatial-Frequency Deepfake Detection](https://github.com/ae1207/spatial-frequency-deepfake-detection)

My final year project on deepfake detection, combining Xception image features with FFT-based frequency features. I compared it with a spatial-only model and explored how face cropping, compression, and different datasets affect detection.

### [Televault](https://github.com/ae1207/televault)

A Python Telegram bot for downloading supported public videos from YouTube, Instagram, and TikTok. It uses yt-dlp and FFmpeg, with options to retrieve captions, thumbnails, and media information.

### [CTF Writeups](https://github.com/ae1207/writeups)

Writeups from CTFs I've taken part in, including NETSA and SillyCTF. A place to keep my solutions and look back at how I approached the challenges.

### [NBA Data Wrangling & Visualisation](https://github.com/ae1207/nba-s2324)

University coursework using an NBA 2024 dataset for data wrangling and visualisation.
